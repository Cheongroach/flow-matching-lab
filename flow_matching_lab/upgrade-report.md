# 项目级别、已完成的改进与下一步难点

判断日期：2026-10-25。这里的分档是工程判断，来自本仓库已完成的实验及公开方法资料，不是学术榜单认证。

**原始版本属于“小玩具到入门大作业”；此次升级后属于“扎实的大作业 / 入门研究复现”。Flow Matching 本身是主流方法，但采用它不会自动让项目达到主流系统或 SOTA 水平。**

## 为什么这样分档

| 级别 | 本报告采用的标准 | 当前项目 |
|---|---|---|
| 小玩具 | 小数据、基础公式、能生成或演示，验证与对照较弱 | 原始交互的应用规模接近这一档 |
| 大作业 | 实际训练、可重复评估、对照、失败结果、交互和正确性验证 | 升级版达到这一档 |
| 一般工程 / 研究项目 | 更真实的任务与数据、较充分调参和消融、标准评估、可靠部署 | 尚未达到 |
| 主流系统 | 能接入成熟模型生态，质量、可控性、吞吐与运维有竞争力 | 尚未达到 |
| SOTA | 在明确任务、标准数据及公平预算下超过强基线，可复现且贡献明确 | 没有此类证据 |

原始版本已经有三个训练种子、解析验证、官方路径逐值校验和生成数组，因此并非只有动画的假演示。限制在于 14×14 MNIST、MLP、噪声纹路编辑，既不覆盖真实图像生成，也没有草图条件训练。面向 AI Infra 简历，单独写“复现 FM 并做画板”仍不足以证明系统工程深度。

## 这次真正做了什么

把输入从“只能修改初始噪声”扩展到“显式传入已知像素和 mask”，训练一个完整 28×28 的图像条件 U-Net。固定噪声时，修改已知笔画会改变未知区域；采样在每一步把已知区域投影回线性路径，终点精确保留输入。

\[
x_t=(1-t)x_0+t x_1,\quad
\mathcal L=\mathbb E\|v_\theta(x_t,t,c,k,m)-(x_1-x_0)\|^2,
\quad
x_t^{\mathrm{known}}=(1-t)x_0^{\mathrm{known}}+t k.
\]

网络条件是时间、类别、已知像素和二值观察 mask；50% 样本普通生成，50% 样本使用半图或矩形遮挡。CFG 只引导类别，条件和无条件类别分支仍保留相同图像观察。

加入两种 MLP 对照：width256 的双种子对照，以及 width1024 的单种子加宽对照。使用同数据切分、同 sampler RNG、batch64、3,000 次更新及同评估噪声，避免用不同分辨率的指标包装收益；不把“同更新次数”说成“同计算成本”。

| 32 步 Euler、CFG 1 | 参数 | 种子 | 类别一致率 | MNIST 特征 Fréchet ↓ | 原始像素 W1 ↓ |
|---|---:|---:|---:|---:|---:|
| MLP256 | 1,259,280 | 2 | 38.55% ± 0.07% | 405.69 ± 1.31 | 0.3706 ± 0.0047 |
| MLP1024 | 9,674,256 | 1 | 70.70% | 289.15 | 0.0372 |
| U-Net16 | 236,545 | 2 | 89.35% ± 0.49% | 14.36 ± 0.88 | 0.0339 ± 0.0002 |

相对加宽 MLP 的单次结果，U-Net 类别一致率提高 18.65 个百分点，特征 Fréchet 降低约 95.0%。参数量少约 40.9 倍，但共享 CPU 上 U-Net 卷积训练仍更慢；参数少不能直接解释为训练快。对照未分别充分调参，不能推断所有 MLP 都差于所有 U-Net。

半图补全使用未参加训练的测试图。U-Net 两次结果的未知 MAE 均值为 0.2292，普通生成后粘贴为 0.3057，相对降低约 25.0%。训练数据中的矩形和上下半图 mask 没有在此次正式评估中分别报告，不能把左半图结论泛化到任意形状。

MLP1024 的补全 MAE 为 0.5701，其粘贴对照为 0.4351，反而恶化约 31.0%。这个失败保留在 [完整结果](improved/results.md) 中。已知像素误差为 0 是人为投影约束，属于接口正确性；只能用未知区域的改善支持学到条件补全。

交互增加白笔、黑笔、擦除约束、真实半图、图片上传、固定种子、恢复和保存。11 项 CPU 单元检查通过；真实 HTTP 推理验证了确定性、噪声/笔画变化、全观察输入精确保留、六种非法请求拒绝和保存回读。Chromium 在此环境页面导航时退出，浏览器自动化未通过，不能宣称画板操作已经得到端到端验证。

## 指标揭示了什么问题

**高类别分数不能代替生成质量。** U-Net 一步类别一致率约 99.65%，但类内像素方差只有真实数据的约 2.4%，特征距离约 721；它生成的是容易识别的平均原型。32 步 CFG1 的类别分数约 89.35%，特征距离约 14.36，方差比例约 0.93，分布更合理。

**一个简单距离可能漏掉结构问题。** 加宽 MLP 的原始像素 W1 已接近 U-Net，生成图却仍有噪点，CNN 特征距离也明显更差。必须同时看固定样例、语义一致性、分布与多样性。

**补全没有唯一答案。** 同一左半图可能有多种合法右半图。对单一目标计算 MAE 会惩罚合理但不同的补全；背景像素还会稀释笔画误差。评估 JSON 另外报告目标笔画像素（归一化值 >0）和背景误差，后续需要多样本、边界连续性、人类偏好及更真实 mask 的评估。

CNN 真实测试准确率为 98.75%；特征 Fréchet 和 cubic MMD 来自它的 128 维特征，**不是 Inception FID/KID**。没有与外部模型榜单比较。两个训练种子的标准差只显示有限重复实验的离散程度，不是泛化保证或置信区间。

## 往上做，具体会遇到什么

| 下一档的方向 | 应做的实际工作 | 最容易卡住的问题 | 足够支持结论的证据 |
|---|---|---|---|
| 从大作业到一般项目：真实输入控制 | 用用户草图、稀疏笔画、形态变化及随机 mask 训练；扩展 EMNIST / Fashion-MNIST 或 CIFAR-10，先完成端到端闭环 | 现在训练的是半图/矩形；稀疏草图、照片存在分布差异。只换更大模型无法补齐条件分布 | 独立测试输入、按 mask 类型拆分、失败样例及至少三个种子 |
| 更可信的评估 | 增加强基线和消融：图像条件移除、不同网络、生成/补全比例、EMA、CFG、预算扫描 | 分类分数易被原型提高；MAE 偏好平均补全；小样本距离波动大 | 标准实现、相同预处理和采样预算、更多样本、独立人工评估 |
| 更好的质量与更少步数 | 对照 time sampling、OT 配对、reflow 或蒸馏；验证 4/8/16/32 NFE 的质量变化 | 改训练路径会影响 ODE 稳定性；OT 有批间求解成本；蒸馏继承教师误差且会损失多样性 | 同预算质量曲线、教师/学生与总训练成本、失败与退化范围 |
| 从数字到高分辨率主流生成 | 基于成熟 latent FM/rectified-flow 模型，加入 VAE、文本编码器及草图/结构条件 | 数据版权与清洗、VAE 细节损失、语义控制、显存、长序列 attention、训练资源 | 公开任务与标准基线上的可控性和质量，可靠模型加载与推理 |
| AI Infra 项目：降低真实服务成本 | 在较真实的预训练模型上做 BF16、compile/graph、CFG 合批、动态 batching、最新输入优先、取消旧请求和分阶段预览 | 生成要连续运行整张网络；CFG 翻倍；不同 NFE 请求拖慢批次；过时画板请求挤占计算；异步结果可能覆盖新输入 | 固定质量约束下的 P50/P95、有效 images/s、峰值显存、GPU 利用率、失败率、每张成本 |
| 到 SOTA | 在一项具体任务提出可证伪的新贡献，并超过调好的强基线 | 主流研究已有大规模数据/模型/训练；“新写一个 U-Net”没有新颖性，局部收益可能来自预算或评估选择 | 开放代码/权重、充分消融、公平预算、标准测试集和外部复现 |

像素从 28×28 升到 256×256 是约 83.6 倍的数量；激活和特征图成本随架构变化，还会增加通道、层数和条件编码。Transformer 的 attention 成本取决于 patch / latent token 数，不能简单把像素数量平方当作所有模型的成本公式。实际常从 latent 表示和预训练模型起步。

推理时 `Euler steps=N` 表示 N 次速度评估，Heun 同步数需要 2N 次。CFG1 是一条网络分支；CFG2 需要条件/无条件两条分支，即每样本网络计算次数翻倍。减少 NFE 对交互延迟很直接，但当前一步模型的原型化说明必须约束质量，不能只比较耗时。

## 对 AI Infra 方向的建议

最有价值的下一步是：**选一个规模适中的预训练 FM/rectified-flow 模型，在真实 GPU 上完成交互推理服务与质量约束下的性能对照。** 本次 CPU MNIST 结果适合作为理解方法与验证接口的起点。

先固定模型、分辨率、mask、随机噪声和质量门槛，再建立端到端基线；分别衡量模型计算、排队、编码/解码、网络传输。逐步加入精度和编译、CFG 合批、不同 NFE 的调度、过时请求取消及负载控制。任何一个有效改进都要给出前后指标和退化边界。

简历可写清这次已完成的范围：“实现图像条件 FM 与约 24 万参数 U-Net，在固定 28×28、3,000 更新实验中完成 MLP 对照，补全未知 MAE 较生成后粘贴下降约 25%，补齐采样约束和真实 HTTP 验证。”在没有 GPU 服务实测前，不写推理加速倍数、生产吞吐或 SOTA。

- `image_eval.py` / `image_aggregate.py`：固定输入评估、汇总与失败结果。
- `draw.py` / `editor.html` / `http_check.py`：交互服务、画板与实际推理验证。
